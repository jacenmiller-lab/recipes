# Chaffles

## Instructions

1. Preheat the waffle maker.
2. In a bowl, stir together all the ingredients for the version you're making. Sprinkle in the psyllium husk gradually so it doesn't clump.
3. Pour in enough batter for one waffle (about one egg's worth), close, and cook 3–4 minutes, until golden and the steam stops.
4. Remove and repeat with the rest of the batter.
5. Let them sit for a minute to crisp up before serving.

## Notes

- The basic version is neutral and bread-like, so it works well for sandwiches.
- Each waffle is 1 egg's worth of batter, so the egg count tells you how many waffles you'll get.
